# Mahima Research Submission — EXOARCHIVE

This folder contains six working research deliverables for EXOARCHIVE.

## Files
- `equipment_database.csv` — structured mission/equipment records.
- `mission_history.md` — historical mission research.
- `scientific_discoveries.md` — observations, evidence, and interpretations.
- `mission_failure_analysis.md` — failure and mission-end analysis.
- `landing_coordinates.csv` — landing-site coordinates and verification fields.
- `research_references.md` — bibliography and source log.

## Important
This is a research starter pack, not a fully verified scientific dataset or a claim that all work has already been completed. The sample records and coordinates must be checked against primary mission/PDS records. Update `verification_status`, add exact citations, and record the researcher's real contributions before committing.

Do not label all inactive equipment as abandoned or all mission endings as failures. Distinguish confirmed facts from hypotheses and unknowns.

## Suggested GitHub contribution workflow
1. Create a branch such as `mahima/research-documentation`.
2. Complete and verify the data and references.
3. Commit each logical set of changes with descriptive messages.
4. Open a Pull Request describing what was researched, what sources were used, and which entries remain uncertain.
5. Do not claim authorship of research that was not personally performed.
