## How to use this reference list

Add every source used in the six research files. Each source entry should include:
- Author or responsible organization.
- Publication date (use `n.d.` only when no date is available).
- Exact title of the page, report, or paper.
- Publisher, journal, or repository.
- DOI or stable URL.
- Access date for webpages and datasets.
- Which EXOARCHIVE claim or file the source supports.

Prefer primary mission records and peer-reviewed literature. A search result snippet is not a reference. Check that each URL opens and supports the claim cited.
